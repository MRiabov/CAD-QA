related work and citations.

`YYYY-<slug>.md`, holding the citation, the method, the findings, and why the study matters
for CAD-QA. The project's own findings stay in their home docs (`../prior-art.md`,
`../evaluation/`, `../train-and-eval/fine-tuning/`); this folder links to them rather than restating them.
