# CAD-QA Epics And Stories

CAD-QA is now planned as one graph-first benchmark system:

```text
typed CAD ontology graph + deterministic query/verifier + hop-counted prompts
```

Earlier category names are implementation history. Low-hop source/statistic
rows and BrowseComp-style high-hop rows are generated by the same query program
and prompt renderer.

The canonical epic structure is maintained in
[`epics-and-stories.yaml`](epics-and-stories.yaml):

1. Project framing and graph-first spec.
2. Source ingestion and normalization.
3. Trace and snapshot execution.
4. CAD ontology graph extraction.
5. Query program and deterministic resolver.
6. Label and relation families.
7. Rule-based prompt rendering.
8. Dataset materialization, splits, and validation.
9. Baselines and evaluation.
10. Training and SFT artifacts.
11. Experiment orchestration and reports.

Every implementation story should name the graph layer it belongs to and avoid
task-family-specific generators that bypass the query program.
