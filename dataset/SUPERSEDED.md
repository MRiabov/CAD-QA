# Superseded

This package is the pre-rebuild dataset generator. It is kept only so the tagged
pre-rebuild release remains reproducible.

- Tag: `before-throwing-out-the-existing-dataset-generator`
- Archived documentation: `docs/_archive/dataset-pre-rebuild-2026-10-21/`
- Replacement requirements: `docs/dataset/PRD.md`

Do not extend this package. New generator work goes into the replacement package
described by the new PRD. The old package is expected to be deleted once the
replacement produces a release and downstream training/evaluation has migrated.
